一、系统简介

本系统是一套 车间数字化台账工具，包含两大业务模块，全部运行在一个轻量服务中，无需安装数据库、无需联网：

模块一 · 铜线出入库台账

  • 生产对比表：生产车间登记每日各型号漆包线「BOM 重量 vs 实际重量」，自动算差重。
  • 仓库铜线领用表：仓库登记漆包线「领出 / 回库 / 线头报废 / 实际用量」。

两张表相互独立——仓库记「实际领用」，生产记「单台用量对比」。

模块二 · 小型工具管理台账

  • 工具档案、借用归还（扫码）、维修报废、盘点、统计报表、工具领用。
  • 看板含：库存排行、逾期未还、安全库存预警、保养到期提醒。

二、运行环境与访问

项目说明
服务端运行时Node.js ≥ 22（需 --experimental-sqlite 开关；Node 24 起已稳定）
数据库SQLite 单文件 data.db（随程序目录，无需安装）
默认端口8090（可用环境变量 PORT 修改）
初始账号用户名 admin　密码 admin123（首次登录后请立即在「用户管理」修改）
客户端任意现代浏览器（Edge / Chrome / 手机浏览器均可）
访问方式：服务器本机打开 http://localhost:8090；同一局域网内其他电脑/手机打开 http://<服务器IP>:8090。服务器 IP 可在服务器上执行 ipconfig（Windows）查看「IPv4 地址」。

三、角色与权限总览

系统设三种角色，权限为前后端双重校验：无权限的菜单不显示，直接输入网址会自动跳回首页，调用接口返回 403 拒绝。

角色可见菜单典型使用者
系统管理员全部页面 + 用户管理 + 数据备份与恢复车间主管 / IT 负责人

五、系统管理员指南

系统管理员拥有全部功能，额外负责账号与数据管理。

5.1 用户管理（用户管理菜单）

  1. 「新增用户」：填写用户名、姓名、密码，选择角色（admin / production / warehouse）与部门/班组。
  2. 「编辑」：修改姓名、角色、部门；修改密码需由用户在登录后自行修改，或管理员重置。
  3. 角色决定该账号能看到哪些菜单（见第三章），请按岗位准确分配。
建议至少配置两名管理员账号，避免唯一管理员密码遗忘导致无法登录。

5.2 数据库备份与恢复

  • 自动备份：系统每天 15:00 自动把数据库备份到程序目录 backups/ 文件夹（文件名 auto-YYYYMMDD-HHMMSS.db），自动保留最近 30 份，无需人工干预。
  • 手动备份：首页点「💾 备份数据库」（仅管理员可见）下载 backup-日期.db；或在「用户管理 → 数据备份与恢复」点「下载当前备份」。
  • 恢复（图形化）：进入「用户管理 → 数据备份与恢复」：
    1. 「选择备份文件恢复」：从本机选取一个 .db 备份文件即可一键恢复；
    2. 下方「自动备份列表」对每个备份提供下载 / 恢复 / 删除按钮，可一键从中恢复。
    恢复前系统会先自动备份当前数据（存为 pre-restore-时间戳.db），万一恢复有误可再次用该文件回退。
  • 恢复（手工）：把备份文件改名为 data.db（同时覆盖 data.db-wal / data.db-shm）覆盖程序目录下的同名文件，重启服务即可（部署时若使用了 DATA_DIR，则覆盖该目录下的 data.db）。

5.3 版本信息

页脚与导航栏显示当前版本（v1.0.2）。版本号由更新日志自动计算；如需发布新版本，可在「版本」接口叠加说明。

六、生产车间指南

生产车间只能看到「总览看板」与「生产对比表」。

6.1 录入生产对比表

  1. 打开「生产对比表」，点「新增」或直接在录入区填写。
  2. 顶部填：日期、生产任务单号、BOM 号。
  3. 明细行填：铜线规格型号、类型（单相/三相/永磁，可不选）、主线线模、副线线模、BOM 重量(kg)、实际重量(kg)，系统自动算 差重 = BOM − 实际。
  4. 一个任务单可点「+ 增行」录多种线径规格；点行尾 ✕ 删行。
  5. 保存后可在下方列表查看、编辑、删除；支持按日期/任务单/规格筛选。
「实际重量」列可手填（空值会显示「实际重量」提示文字，米黄底色表示可编辑）。差重由系统自动计算，无需手填。

6.2 汇总与对比

「按 BOM 号汇总」：同 BOM + 同任务单内不同线径先合计，同 BOM 跨任务单再取平均值，用于判断是否需要修改 BOM（超差阈值 10g）。

七、仓库管理员指南

仓库管理员负责铜线领用与全部工具台账。

7.1 仓库铜线领用表

  1. 打开「仓库铜线领用表」，填写：日期、生产任务单号、线径规格、领出重量(kg)、回库重量(kg)、线头报废重量(kg)。
  2. 系统自动算 实际用量 = 领出 − 回库 − 线头报废。
  3. 一个任务单可点「+ 增行」录入多种线径规格。
  4. 保存、查询、编辑、删除、打印、导出 Excel 均支持。
此表只记录仓库实际领用，与生产对比表的「单台用量对比」相互独立，不记录 BOM 差重。

7.2 工具台账（档案 / 借还 / 维修 / 盘点 / 报表 / 领用）

  • 工具档案：每件工具建卡（自动编号、序列号、品牌型号、位置、采购、照片、安全库存、保养周期），支持批量打印二维码标签。
  • 借用归还：扫码枪/手工输入编号，自动识别借或还；归还检查状态，损坏自动转维修。
  • 维修报废：维修保养登记（费用/原因）后回库；报废登记（原因+批准人）移出在册。
  • 盘点：一键生成盘点单，扫码清点，结束自动出盘盈盘亏报告。
  • 统计报表：个人未还清单、周转率/使用率、维修报废统计。
  • 工具领用：登记新领 / 报废换新 / 维修调换，含领用人、班组、日期、用途。

九、公共功能（所有角色通用）

9.1 查询与筛选

各表上方均有「日期范围 / 单号 / 规格」等筛选条件，点「查询」即按条件过滤；「重置」恢复全部。

9.2 打印（含签字栏）

点「打印」调用浏览器打印，页面自动带标题、导出人、打印时间；生产/仓库表含仓库管理员 / 复核 / 主管签字栏。建议打印前在浏览器打印设置中选择「横向」并勾选「背景图形」。

9.3 导出 Excel

点「导出 Excel」下载带样式的 .xlsx：标题居中、表头底色、合计行、签字栏一应俱全，可直接用于归档或上报。

9.4 修改密码

管理员在「用户管理」重置他人密码；个人可在登录后通过管理功能修改自己的密码（具体以用户管理页为准）。

十、扫码操作说明

  • 扫码枪（推荐，即插即用）：光标点在「工具编号」输入框，扫工具上的二维码标签即可，无需任何设置。
  • 二维码标签：在「工具档案」勾选工具 → 点「打印二维码标签」，用普通打印机或标签机打印后贴在工具上。
  • 手机操作：同一局域网内用手机浏览器打开系统，可手工输入编号完成借还/领用。

十一、常见问题（FAQ）

问题处理
打不开页面确认服务器已启动；检查防火墙是否放行 8090 端口；手机/其他电脑用服务器 IP 访问而非 localhost。
端口被占用修改启动命令加 set PORT=9000，或 Docker 改端口映射左边值。
忘记管理员密码用另一管理员账号重置；或直接覆盖 data.db 恢复备份（会丢失备份后新数据，慎用）。
页面显示异常浏览器按 Ctrl+F5 强制刷新，清除缓存。
换了角色后菜单没变重新登录（退出后再登录），权限在登录时加载。
